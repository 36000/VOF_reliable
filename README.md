This repo contains scripts for running analyses and making plots associated with the paper "Automatic and Reliable Vertical Occipital Fasciculus Recognition". 

Scripts for running analyses are located in vof. All other scripts pertain to plot making. 

Figure #1 is in the folder intro_fig.

Figure #2 is in berk_sub. 

Figure #3 is made by running combined_fig after running hbn_sub/viz.py and hcp_sub/viz.py

Figure #4 is made by running discrim_rel.py

Figure #5 is made by running robust_fig after running hbn_sub/simply_sim.py and hcp_sub/simply_sim.py

Figure #6 is made by running endpoints_fig after running plot_cortex.py and hcp_sub/endpoints_make_plot.py

All scripts rely only on pip-installable Python libraries and were run with Python 3.12.12 and pyAFQ 3.3
